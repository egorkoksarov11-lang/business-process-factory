# Examples

Здесь должны храниться только проверенные эталонные примеры, которые агенты могут использовать как образец структуры и качества.

План пилотного наполнения:

1. `HR — подбор и прием сотрудника`:
   - L0/сквозной view;
   - L1 end-to-end процесс;
   - L2 «Формирование заявки на подбор»;
   - пример Change Log;
   - пример нового чек-листа/шаблона.

2. `Бухгалтерия — обработка первичного документа`:
   - объединение материалов нескольких интервью/ролей;
   - пример cross-process проблемы;
   - пример организационной оптимизации без обязательной автоматизации.

## Правило эталона

Не помещать сюда черновик только потому, что он существует. Пример становится эталоном после проверки:
- корректности границ;
- evidence trace;
- AS-IS;
- change log;
- TO-BE;
- semantic QA;
- visual QA.
