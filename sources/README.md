# Sources

Здесь хранятся исходные материалы и metadata источников.

Рекомендуемая структура:

```text
sources/
├── raw/          # исходные интервью, анкеты, схемы, документы
├── normalized/   # нормализованные текстовые версии при необходимости
└── metadata/     # YAML с source_id и описанием источника
```

## Правила

1. Исходник не переписывать аналитическими выводами.
2. Каждому источнику присваивать стабильный `source_id`.
3. Сохранять роль интервьюируемого отдельно от имени.
4. Если один источник относится к нескольким процессам — ссылаться на него из каждого process package, а не копировать содержимое.
5. Уточняющее интервью добавлять как новый source, а не заменять старое.
6. Любые исправления транскрипции, влияющие на смысл, отмечать явно.

Для структурированной фиксации фактов использовать `templates/evidence.yaml`.
